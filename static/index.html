Truth layer for marketing PDFs

Fact-Check Agent

Upload a PDF. The app pulls out the numbers, dates and named facts, searches the live web for each one and tells you which are correct, which are out of date or wrong, and which have nothing behind them. Wrong claims come with the real figure and a source.

Built by Shubham Kumar. Live search with Perplexity Sonar (Google results as backup), verdicts by a separate checking model. Source on GitHub
